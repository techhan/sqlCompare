# SQL 로그 비교기

ASIS·TOBE SQL 로그를 붙여 넣으면 같은 쿼리인지 판정하고, 다른 곳을 하이라이트한다.

**접속 주소**: [https://techhan.github.io/sqlCompare/](https://techhan.github.io/sqlCompare/)

입력한 SQL은 브라우저 안에서만 처리하고, 저장하거나 외부로 보내지 않는다.

## 사용 방법

1. 왼쪽에 ASIS, 오른쪽에 TOBE SQL을 하나씩 붙여 넣는다.
   - **SQL문만 넣는다.** 로그 앞뒤의 시간, 스레드, 로거 이름, 실행 시간, 조회 결과 행 같은 다른 정보는 지운다. 남아 있으면 SQL의 일부로 비교되어 "다름"이나 "오류"가 나온다.
   - <img width="1023" height="564" alt="image" src="https://github.com/user-attachments/assets/525ee214-7052-405b-963a-7795437f5c48" />
   - 파라미터가 값으로 들어간 SQL 기준이다. `?`나 `:1`이 남아 있으면 값으로 치환해서 넣는다.
2. 상단 판정을 확인한다.
3. 차이 목록에서 행을 누르면 정규화 결과의 해당 위치로 이동한다.
4. 다른 쿼리를 비교할 때는 **초기화**를 누른다.

   
## 판정

| 판정 | 의미 |
|---|---|
| 같음 | 정규화 후 완전히 같음 |
| 같음 (허용 차이 n건) | 허용 규칙이나 값 무시에 해당하는 부분만 다름. 파란색으로 표시 |
| 다름 (n곳) | 그 외 차이가 있음. 빨간색으로 표시 |
| 오류 | 입력이 비었거나 따옴표·주석이 닫히지 않음 |

## 값 무시

- 켜면 문자열·숫자 값이 달라도 같다고 본다. 다른 값은 파란색으로 표시한다.
- INSERT는 VALUES의 값 자리 전체를 무시한다. `{ts '...'}`, `SYSDATE`, `TO_DATE(...)`처럼 모양이 달라도 "값"으로 본다. 컬럼 목록, 개수, 순서는 그대로 비교한다.
- 양쪽 모두 INSERT면 자동으로 켜진다. 직접 끌 수도 있다.
- SELECT, UPDATE, DELETE는 기본으로 꺼져 있다. WHERE 조건값까지 검증하려면 끈 상태로 비교한다.

## 정규화 규칙

| ID | 규칙 |
|---|---|
| N1 | 주석 제거 (`--`, `/* */`). 따옴표 안은 주석으로 보지 않음 |
| N2 | 힌트 `/*+ */`는 지우지 않고 비교 |
| N3 | 공백·탭·개행은 구분자로만 사용 |
| N4 | 따옴표 밖 단어는 대문자로 통일. 큰따옴표 식별자는 그대로 |
| N5 | 문자열 리터럴은 원문 그대로 비교 |
| N6 | 연산자 사이 공백 붙임: `< >`→`<>`, `> =`→`>=`, `< =`→`<=`, `! =`→`!=` |
| N7 | 끝의 `;` 하나는 무시 |
| N8 | NBSP·전각 공백 같은 특수 문자는 지우지 않고 `[U+XXXX]`로 표시해 비교 |
| N9 | 큰따옴표 식별자: 안이 전부 대문자면 따옴표 없는 이름과 같게 봄 (`"COL"` = `COL`). 소문자가 섞이면 그대로 비교 |

## 허용 규칙 (공통 차이)

UPDATE의 SET 절과 INSERT의 컬럼-값 짝에서만 적용한다. WHERE 절에는 적용하지 않는다.

| ID | 컬럼 | 조건 |
|---|---|---|
| A1 | UPDATE_DATE | TOBE 값이 `SYSDATE`면 허용 |
| A2 | UPDATE_MAN | 양쪽 값이 모두 문자열이면 허용 (ASIS 사용자명 → TOBE 사용자 ID) |
| A3 | `'0' AS CHK` | TOBE 메인 SELECT 목록에만 있으면 허용 (멀티로우 삭제용 체크 컬럼). 서브쿼리·WHERE에는 적용 안 함 |
| A4 | DELETE FROM | `DELETE` 바로 뒤 `FROM`이 한쪽에만 있으면 허용 (Oracle에서 FROM 생략 가능) |

## 하지 않는 것

- 값 형식 통일: `'10'`과 `10`, `1.0`과 `1`은 다르다.
- 컬럼·조건 순서 재배열
- 의미가 같은 다른 표현 통일: `!=`와 `<>`, alias, JOIN 문법, NVL과 COALESCE
- 여러 쿼리가 섞인 로그 짝맞추기: 쿼리는 하나씩 넣는다.

## 허용 규칙 추가

`index.html`의 `ALLOWED_RULES` 목록에 항목을 추가한다. 수정한 뒤에는 `VERSION`을 올린다.
